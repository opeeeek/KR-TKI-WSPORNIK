## KRÓTKI WSPORNIK ST — wersja dla Windows (64-bit)

Program do projektowania i sprawdzania krótkich wsporników żelbetowych metodą Strut-and-Tie wg PN-EN 1992-1-1.

### Którą wersję pobrać?

* **`KrotkiWspornikST-1.0.0-setup.exe`** — instalator (zalecane). Uruchom, kliknij „Dalej” — program pojawi się w menu
  Start i na pulpicie, pliki projektów `.kwst` otwierają się dwuklikiem.
* **`KrotkiWspornikST-1.0.0-portable-win64.zip`** — wersja bez instalacji: rozpakuj i uruchom `KrotkiWspornikST.exe`.

### Ostrzeżenie Windows SmartScreen

Program nie ma płatnego podpisu cyfrowego, więc przy pierwszym uruchomieniu Windows może pokazać okno
„System Windows ochronił ten komputer”. Kliknij **„Więcej informacji”**, a następnie **„Uruchom mimo to”**.

### Uwaga

Wyniki wymagają weryfikacji przez uprawnionego projektanta. Przed użyciem w dokumentacji potwierdź parametry NDP
w zakładce *Parametry normowe*. Szczegóły: `docs/UZYTKOWNIK.md`, `docs/METODYKA.md`, `docs/WALIDACJA.md`.
